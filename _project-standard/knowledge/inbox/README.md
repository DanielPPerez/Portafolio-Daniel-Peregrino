# inbox/ — archivos crudos por convertir

Deja aquí los archivos originales (PDF, DOCX, XLSX, PPTX, imágenes, audio) que quieras convertir a
Markdown con [`../../skills/markitdown.md`](../../skills/markitdown.md).

El resultado `.md` va en la carpeta superior [`../`](../), donde la IA lo puede leer.

> Esta carpeta existe para no perder los originales. Puedes borrar de aquí lo ya convertido si no
> necesitas versionar el crudo. No subas datos sensibles (ver [`../../rules/04-security.md`](../../rules/04-security.md)).
